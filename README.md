# قطّة الاستراحة

موقع عربي بسيط لتسجيل تحويلات القطّة الشهرية ومتابعتها من الجوال.

## الوظائف

- صفحة عامة لاختيار الاسم ورفع إيصال JPG أو PNG أو PDF.
- منع التسجيل المكرر مع خيار تحديث الإيصال.
- لوحة مسؤول محمية بكلمة مرور.
- متابعة من حوّل ومن لم يحوّل وعرض الإيصالات.
- إضافة الأعضاء وحذفهم وتغيير مبلغ القطّة.
- بدء قطّة جديدة مع إبقاء الأسماء والمبلغ.

## التشغيل محليًا

يتطلب Node.js 22.13 أو أحدث.

1. ثبّت الاعتماديات:

   ```bash
   npm install
   ```

2. انسخ `.env.example` إلى `.dev.vars`، ثم ضع رقمًا سريًا للمسؤول ونصًا عشوائيًا طويلًا للجلسة.

3. أنشئ ملفات ترحيل قاعدة البيانات عند تعديل المخطط:

   ```bash
   npm run db:generate
   ```

4. شغّل الموقع:

   ```bash
   npm run dev
   ```

5. افتح `http://localhost:3000`، وصفحة المسؤول في `http://localhost:3000/admin`.

## متغيرات البيئة

| المتغير | الغرض |
|---|---|
| `ADMIN_PASSWORD` | الرقم السري لدخول المسؤول |
| `ADMIN_SESSION_SECRET` | نص عشوائي طويل لتوقيع جلسة المسؤول |

لا تحفظ القيم الحقيقية داخل Git. ملف `.dev.vars` مستبعد تلقائيًا.

## البناء والنشر

تحقق من نسخة الإنتاج محليًا بالأمر:

```bash
npm run build
```

المشروع مهيأ للنشر عبر OpenAI Sites، ويستخدم D1 لحفظ الأعضاء والتحويلات وR2 لحفظ ملفات الإيصالات. عند النشر يجب ضبط متغيري البيئة المذكورين أعلاه في إعدادات الموقع.

## ملاحظات الأمان

- الإيصالات لا تُعرض إلا بعد تسجيل دخول المسؤول.
- الرفع يقبل JPG وPNG وPDF فقط، وبحد أقصى 10 ميجابايت.
- حذف العضو يعطّله من القوائم الجديدة ويحافظ على سجلاته السابقة.
